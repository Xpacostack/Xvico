- **3D key focus**: selecting a physical key frames and rotates the model, revealing the Siri side button. Closing or ending a drag restores the appropriate pose. Remove visible hit-zone rings, restrain the selection glint, sharpen rendering with high-density MSAA and fix opaque black backing in light mode.
- **语音后台不再固定一小时结束**：移除手动启动会话的固定截止，保留启动超时、主动停止、进程/连接丢失处理及诊断恢复。应用启动、安装或唤醒仍不会自动开始采集；后台待命不等于持续收音。
- **No fixed one-hour backend deadline**: manually started sessions no longer expire at a fixed duration. Startup timeouts, explicit stop, client/connection-loss handling and diagnostic restoration remain. Launch, installation and wake do not start capture, and backend availability does not keep the microphone open.

## 升级注意 / Upgrade notes

**语音取消固定时限需要更新后台组件。** 更新主程序后，在语音页按提示亲自批准一次后台组件更新，再手动启动。保存过的后台授权不代表旧组件会自动换成新版。公开构建采用临时自签名身份，macOS可能要求重新批准辅助功能/输入监控等权限及后台安装。个人映射与场景配置继续沿用，不要为升级删除配置。

**The new voice behavior requires the updated backend payload.** After upgrading the app, approve the backend update in Voice Settings, then start it manually. Saved approval does not automatically replace an older payload. Public builds use disposable signing identities, so macOS may require renewed privacy approval and helper installation. Keep existing mappings and scenes; do not delete configuration for this upgrade.
