## 本次更新 / What's new

- **统一配置与恢复**：全局设置、应用场景、快捷指令和学习映射使用同一份配置文件；支持热重载、外部编辑冲突提示、最近有效副本和未保存配置恢复。旧设置首次迁移前保留本地归档，系统权限和后台授权独立保存。
- **Unified configuration and recovery**: settings, scenes, shortcuts and learned mappings share one document, with hot reload, conflict handling, last-valid recovery and an unsaved-edit recovery path. Legacy settings are archived locally before migration; system and backend permissions remain separate.
- **可靠按键行为**：统一编辑与执行的映射解析，新增实际场景和输出诊断；修复持键期间改模式后松键遗漏、跨场景误合成双击、旧计时回调和断连残留输出。
- **Reliable button behavior**: one resolver powers editing, execution and diagnostics. Fix captured-key releases after mode changes, double taps crossing scene boundaries, stale timers and stuck output after disconnects.
- **点击与拖动手感**：增加中心点击稳定、精准/均衡/快速指针响应和可调拖动加速。仅实际拖动加速，慢移保持精度；拖动期间不触发外圈动作。
- **Pointer and dragging**: add center-click stabilization, precise/balanced/fast profiles and adjustable drag acceleration. Slow movement remains precise; dragging does not trigger outer-ring actions.
- **语音连续使用**：修复启停命令失败后的状态错位、停止后迟到启动、旧会话回调污染，以及后台结束后仍显示就绪的问题。现有 Siri→输入法触发键映射保持可自定义。
- **Repeated voice input**: fix microphone-toggle state after failed commands, queued starts after stopping, callbacks from old sessions and stale readiness after backend exit. Siri mappings and the input method trigger remain configurable.
- **遥控器自动恢复**：重连时对延迟出现的多点触控通道进行有限重试；无需手动重新识别即可恢复中心点击、滑动和外圈滚动。停止或断连会取消旧恢复任务。
- **Automatic remote recovery**: bounded retries bind a multitouch channel that appears after its HID identity, restoring center clicks, swipes and ring scrolling without manual reidentification. Stop and disconnect cancel obsolete attempts.
- **本机识别与联系入口**：本机识别写入前核对原输入框，焦点改变时保留文字供手动处理；增加阶段耗时诊断，以及微信旁的 Telegram @heitonk 联系入口。新增文案覆盖中、英、日、法。
- **Dictation and contact**: on-device dictation checks the original field before insertion and retains text when focus changes. Add latency diagnostics and a Telegram @heitonk contact beside WeChat. New strings cover Chinese, English, Japanese and French.

## 验证与限制 / Validation and limits

- 发布前本地软件回归：206项通过。真实 Siri Remote 已确认按键/拖动、连续语音、停止后重启语音，以及断连后点击/滑动/滚动自动恢复可用。
- Pre-release local regression: 206 tests passed. Hardware acceptance confirmed normal controls/dragging, repeated voice input, voice stop/restart and automatic click/swipe/scroll recovery after reconnecting.
- 睡眠时清理与唤醒后恢复监听已实现并有软件测试，但维护者电脑禁用了系统睡眠，**真实睡眠唤醒尚未验收**。唤醒不会自动启动语音采集。
- Sleep cleanup and wake-time HID monitoring are implemented and software-tested, but **real sleep/wake acceptance remains pending** because system sleep was disabled on the test Mac. Waking does not automatically start voice capture.
- 硬件通过仅覆盖已测试的 Mac、遥控器和输入法；不代表所有系统版本、输入法或编辑器兼容性都已验证。本机识别的跨编辑器自动落字仍需更多实测。
- Hardware results apply to the tested setup, not every macOS version, input method or editor. Cross-editor insertion for on-device dictation still needs broader acceptance.
- 语音采集继续按需启动，保留单次一小时上限。公开包不附带 Apple PacketLogger/PacketDecoder，需要用户自行取得并导入官方工具。
- Voice capture remains explicit and retains its one-hour session limit. Public packages exclude Apple PacketLogger/PacketDecoder; obtain and import official tools separately.
- GitHub 构建仍为自签名、未公证的 Apple Silicon 测试版。与维护者本机固定签名不同，公开 beta 之间升级可能需要重新批准隐私权限和更新后台组件。
- GitHub builds remain self-signed, non-notarized Apple Silicon betas. Unlike the maintainer's persistent local identity, public beta upgrades may require renewed privacy approval and a helper update.
