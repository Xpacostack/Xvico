# 新版 UI 升级与功能迭代 / UI and feature updates

2026-10-16 · 1.0.0-beta.6

本页描述 beta.6 相对 beta.5 的更新。新版安装包包含以下 UI 和取消固定时限的后台改动；语音变化需在新版中更新后台组件后生效。历史 beta.5 附件保持不变。

This page describes beta.6 updates since beta.5. The new installer includes this UI and backend session behavior; install its updated backend payload for the voice change to take effect. Historical beta.5 assets remain unchanged.

## 界面与交互 / Interface and interaction

- **玻璃导航与弹层**：侧栏导航、连接状态、开始/停止控制和折叠控件使用统一的抬升表面、边缘高光与指针反馈；映射弹层使用窗口内毛玻璃背景，文字保持清晰。浅色、深色分别适配，启用开关保持绿色。
- **Glass navigation and panels**: shared raised surfaces, edge highlights and pointer feedback for navigation, connection status and controls; mapping panels use an in-window frosted backing with clear foreground labels. Light/dark appearance and green enabled switches are consistent.
- **页面整理**：移除冗余顶部标题，折叠控件平滑移到左侧悬浮位置；整理设备、语音、场景及预设页面。相关操作在空间允许时左右排列；应用映射的键位和值按统一列对齐。
- **Page layout**: remove the duplicate top header, animate the floating sidebar toggle, reorganize device/voice/scene/preset pages and align per-app mapping columns. Related controls share a row where space permits.
- **按键聚焦**：模型上的实体按键各有聚焦姿态；Siri 旋转露出侧键，关闭编辑器后返回。拖动可查看背面，松手回到当前聚焦角度。选择模型按键只打开设置，不执行映射动作。
- **Key focus**: physical keys have focused poses; Siri rotates to reveal its side button. Closing restores the resting pose. Drag to inspect the rear and release to return to the selected pose. Model clicks open settings without executing mapped actions.
- **模型显示修正**：提高渲染密度，采用 GPU 支持的 MSAA；修复浅色模式黑底，移除可见按键热区圈并降低点击闪光。系统“减少动态效果”和“降低透明度”有相应回退。
- **Rendering corrections**: higher raster density and GPU-supported MSAA, transparent backing in light mode, no visible hit-zone outlines and a restrained selection glint. Respect Reduce Motion and Reduce Transparency.

## 语音后台 / Voice backend

手动启动的后台会话取消固定的一小时截止。主动停止、退出、客户端丢失、睡眠/断连及子进程异常仍会结束或清理会话；保留启动超时、停止标记和诊断恢复。保存安装授权仍不等于持续收音，也不会在打开应用或唤醒时自动启动采集。

Manually started backend sessions no longer have a fixed one-hour deadline. Explicit stop, quit, client loss, sleep/disconnect and child failure still end or clean up sessions. Startup timeouts, stop markers and diagnostic restoration remain. Saved installation approval does not mean continuous microphone capture or automatic capture on launch/wake.

**需要更新后台组件后生效。** 新载荷首次更新仍由用户亲自批准管理员安装；已有辅助功能/输入监控权限不因这项源码改动而主动重置。详情见[语音生命周期](../voice-lifecycle.md)。

**Requires the updated backend payload.** The user approves the one-time administrator installation of the new payload. This change does not proactively reset Accessibility/Input Monitoring permissions. See [Voice lifecycle](../voice-lifecycle.md).

## 验证范围 / Validation scope

- 当前本地软件回归：212项通过，0失败；四语本地化和源码分发检查通过；不含 Apple 语音运行时的公开结构构建及严格签名检查通过。
- Local regression: 212 tests passed, zero failures; four-language localization/source checks and a public-layout build without Apple audio tools passed, including strict signature verification.
- 新增语音回归运行真实 Runner 循环的模拟依赖，跨越32小时后核对主动停止、客户端丢失、采集退出、路由退出和终止信号。它不等同于32小时真实遥控器/音频运行。
- The voice regression exercises the real Runner loop with simulated dependencies across 32 hours, checking stop, client loss, capture/router exit and termination. It is not a 32-hour hardware/audio soak test.
- 本机检查了中英文界面、模型聚焦和透明背景；此前点击、拖动、连续语音与重连恢复的用户验收保留。真实睡眠唤醒、多设备兼容性和帧率/GPU性能没有扩展为通过结论。
- Local UI checks cover Chinese/English, model focus and transparent backing. Earlier user acceptance for controls, dragging, repeated voice and reconnection remains. Real sleep/wake, all-device compatibility and frame/GPU performance are not newly qualified.
