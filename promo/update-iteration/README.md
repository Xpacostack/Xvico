# Xvico 新版 UI 与功能迭代短片

独立的9:16竖屏补充视频，1080×1920、30fps、40秒。重点是已核对的具体UI升级和功能迭代；不提版本数量，不重复完整的Coding构建故事。内容选择和事实边界详见[更新梳理](更新梳理.md)。

- 0–3秒：新版UI与功能迭代开场。
- 3–9秒：真实玻璃侧栏，浅色过渡深色。
- 9–15秒：Siri / 音量按键聚焦与真实映射面板。
- 15–21秒：点击稳定、拖动加速、慢移精度的动效示意。
- 21–26秒：重连后点击、触控和外圈恢复，实际通道卡片。
- 26–31秒：统一配置、热重载与恢复副本的流程图。
- 31–36秒：取消语音后台固定截止，注明需要更新后台组件。
- 36–40秒：品牌收束。遥控器全程保留。

素材：`../assets/`保存的当前窗口截图，派生裁切不会改写控件。`assets/sidebar-dark.png`来自2026-10-16模型渲染修复后实际深色窗口的侧栏裁切；原图为本机证据`evidence/2026-10-16/model-rendering/final-siri-dark.png`，控件材质没有重新绘制。设备通道卡片来自`app-device.png`。不拍摄或写入个人配置，不启动实际音频后端。

模型、原生Swift渲染器和原创124BPM电子配乐复用科技竖屏版的制作技术，但本片的镜头、文案、节奏与运动轨迹独立。单一模型图层在全部1200帧中持续绘制；完整矩形和三轴旋转以五次曲线连续插值，关键姿态的局部透明边界换算只在初始化进行。

## 重建

macOS + Swift/Xcode SDK + Python3（NumPy、Pillow）：

```sh
./promo/update-iteration/build.sh
```

可用`XVICO_VIDEO_PYTHON=/path/to/python3`指定解释器。主配置为`storyboard.json`，画面和动效源为`render.swift`。`prepare.py`只准备裁切；`finish.swift`合成音画；`validate.swift`完整解码并生成最终MP4提取的分镜图；`deliver.py`写字幕、发布文案与文件哈希。可见模型高度在本项目沿用的关键帧字段`width`中保存，随后换算为完整模型图层矩形。

输出`dist/Xvico-ui-features-9x16.mp4`。字幕标题已出现在画面中，SRT为后续编辑备份。`preview.html`可由本地HTTP服务打开。生成的视频仅在本地导出；本目录源码可随仓库发布，脚本不执行 Git 或抖音上传。
