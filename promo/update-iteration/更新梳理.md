# Xvico 新版 UI 升级与功能迭代

本片作为已有品牌/科技宣传片的补充，用具体更新解释“界面怎么变了，操作怎么更好用”。不出现版本数量，不编造新版本号，不按提交历史逐条播报。

| 方向 | 核对后的实际变化 | 本片表达 |
| --- | --- | --- |
| 导航与材质 | 侧栏导航、连接状态和底部控制共用抬升玻璃表面；浅色和深色适配，移除选中后的左侧蓝条 | 真实侧栏由浅色过渡到深色，突出材质与状态阅读 |
| 结构与空间 | 移除顶部冗余标题；折叠控件平滑移动到左侧悬浮位置；相关设置按实际宽度左右排列 | 不把“更紧凑”当全局目标；用新版界面实录裁切展示 |
| 设置与场景 | 场景编辑的键位/值/操作列对齐；语音状态集中；设备页按键和触控通道区分展示 | 作为真实界面素材；不逐一展开所有布局细节 |
| 映射模型聚焦 | 所有13个实体按键都有聚焦姿态，Siri 露出侧键，关闭面板平滑归位；选择模型只打开编辑器 | Siri / 音量两种实际面板配合连续模型旋转 |
| 渲染与反馈 | 高分辨率渲染及硬件支持的 MSAA；透明背景修复；移除热区圈，降低点击闪光 | 使用清晰模型，不绘制按键热区圈，不宣称 GPU 性能或“零锯齿” |
| 点击与拖动 | 中心点击稳定、三档指针响应、可调拖动加速；慢移保留精度，实际拖动时才加速，拖动绕开外圈动作 | “点得更稳，拖得更远”，演示窗口拖动，注明动效示意 |
| 按键可靠性 | 修复修改模式后的松键遗漏、跨场景误判双击、旧计时器和断连残留输出 | 合并到操作体验，不占用单独的技术说明镜头 |
| 连接恢复 | 重连后对延后出现的触控通道有限重试；已测试设备的点击、触控、外圈可自动恢复 | 真实设备通道卡片配合恢复过程示意；不宣称所有型号/系统已通过 |
| 配置 | 全局行为设置、应用场景、快捷指令和学习映射共用配置；支持热重载、冲突提示、有效副本和未保存恢复 | 一份配置统一管理，热重载无需重启；不展示个人配置内容 |
| 语音生命周期 | 连续输入、停止再启动、旧回调和通道结束后的状态处理更可靠；后台授权与收音会话分离 | 按需启动、主动停止，不把保存授权等同持续收音 |
| 固定时限 | 当前源码已移除三层3600秒固定截止，保留停止、退出、断连及异常检查 | “语音会话，取消固定时限”；明确“更新语音后台组件后生效” |
| 其他 | 本机识别写入前焦点核对、耗时诊断、联系入口与四语文案 | 不塞入本片，避免信息过密 |

## 素材与事实来源

- `docs/releases/1.0.0-beta.5.md`：配置、输入、语音启停与自动重连的历史发布事实。该历史公开版本仍有单次一小时限制，不能用它支持“已公开取消时限”的结论。
- `docs/configuration.md`：热重载、冲突、恢复和操作等待边界。
- `docs/voice-lifecycle.md`：当前源码的不限固定时长行为及后台升级要求。
- `Sources/XvicoApp/Design/`、`Mapping/`、`Views/` 与 `Tests/XvicoAppTests/RemoteModelInteractionTests.swift`：最终界面与模型实现和回归。
- `ThirdParty/SiriRemoteVoiceBridge/Capture.swift`、`ThirdParty/XvicoAudioBackend/BackendRunner.swift`、`BackendHelper.swift` 与 `scripts/test-voice-session-lifetime.py`：取消固定时限和清理条件。
- `docs/releases/1.0.0-beta.5.md` 保留此前点击、拖动、语音及重连的用户验收范围；当前UI/模型检查见 `docs/updates/2026-10-16.md`。

实际硬件结论仅覆盖已有测试设备。睡眠唤醒仍未获得完整实机验收，因此本片没有把它作为更新卖点。固定时限取消以更新后的后台组件为前提，不承诺连接故障或退出后继续采集。片内恢复进度与指针、配置、语音图形是说明用途，不是实际耗时录像。
